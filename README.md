# 👻 Ghost Hunter — Linked List Edition

A CLI horror game built in C++ demonstrating Data Structures & Algorithms (DSA).

## 🧠 DSA Concepts
- Linked List Traversal
- Searching & Distance Calculation
- Dynamic Node Insertion & Deletion
- Cycle Detection (Floyd's Algorithm)

## 🚀 Build & Run
```bash
g++ -std=c++17 -Iinclude src/*.cpp -o ghost_hunter
./ghost_hunter
